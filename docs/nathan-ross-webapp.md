# Nathan Ross Webapp

## User Experience

The mission of the Nathan Ross Web Application is to help the user discover, remember and explore
the life and works of Nathan Ross.

## Components

The main deployable (target) components built by the source artifacts maintained in this repository:

1. Standalone "Nathan Ross" web application, deployed (at least initially) as a sub-component of
   the existing [noodnik2 GitHub Pages](https://github.com/noodnik2/noodnik2.github.io) website.
2. Music Session Explorer - a separate web application that can be invoked from the "Nathan Ross"
   web application, passing the query string "Nathan Ross" in order to retrieve Nathan's recordings
   and follow the links to listen (or otherwise access more details about) those recordings.
