# Music Session Explorer

## User Experience

1. User supplies the name of the artist
2. A paged list of the recording sessions in which that artist appeared as a contributor is displayed to the user.
   The "title" attribute of each entry within this list is a hyperlink to "Recording Details" page.  
3. The "Recording Details" page lists hyperlinks to external details pages related to each recording.

## User Interface

Must be:

- Simple to use
- Uncluttered, and visually pleasing

See a provided example of this page [here](./references/uiconcept-music-session-explorer.webp) which
shows an example implementation.
